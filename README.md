# Royal Chess

A chess game with custom pieces. Play against the computer (Easy, Medium, Hard) or with a friend on the same screen. It works on phones and computers.

## Put it online with GitHub Pages

1. Create a new **public** repository on GitHub, e.g. `royal-chess`.
2. Click **Add file → Upload files** and drag in everything from this folder (`index.html`, `README.md`, and the `pieces` and `icons` folders). Click **Commit changes**.
3. Go to **Settings → Pages**. Under *Build and deployment*, set **Source** to *Deploy from a branch*, choose the `main` branch and the `/ (root)` folder, and click **Save**.
4. After a minute or two, your game is live at
   `https://<your-username>.github.io/royal-chess/`

## Play it offline

Download the folder and open `index.html` in any browser.
